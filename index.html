Realtime TTS
Realtime v3 использует MessagePack по WebSocket. Браузер не может передать Bearer-заголовок при WebSocket handshake. По документации для браузера нужен короткоживущий ticket, который выдаёт доверенный backend. Поэтому прямая реализация Realtime в статическом Pages без backend намеренно не включена.

API PROVIDER
Подключение API

    

    
Приложение обращается к API через ваш Worker. Секреты провайдера хранятся в Worker Secrets, а браузер передаёт только отдельный пароль доступа к Worker.

    
Не публикуйте proxy-пароль.Worker расходует квоту вашего аккаунта. Используйте длинный случайный пароль. Cloudflare Access перед Worker не нужен: он может блокировать CORS preflight OPTIONS.

    
Для Fish Audio требуется отдельный секрет.В настройках своего Worker выполните npx wrangler secret put FISH_API_KEY и вставьте Fish Audio API key. Сам ключ в это приложение на GitHub Pages не вводится.

    

      
      
      
      
      Оба значения хранятся только в памяти текущей вкладки и удаляются после перезагрузки.
